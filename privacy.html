Privacy Policy

Last updated: 25 October 2026

Glowing Master (“the app”) is a private automation tool used by one operator to publish videos to that operator's own YouTube channel. This policy explains what data the app accesses.

Who can use the app

Only the operator signs in to the app, using their own Google account. No other person is invited to sign in, and the app does not offer accounts, registration, advertising, or tracking to visitors or viewers.

Google user data the app accesses

With the operator's consent, the app uses the YouTube Data API and the YouTube Analytics API to:

  • upload videos, thumbnails, titles, descriptions and scheduling settings to the operator's channel;
  • read the operator's own video list and channel analytics (such as views and watch time) to evaluate how published videos performed.

The app does not access Gmail, Google Drive, contacts, or any data belonging to other people.

How the data is used and stored

  • Analytics are used only to evaluate and improve the operator's own videos.
  • The sign-in credential (an OAuth refresh token) is stored as an encrypted secret in the operator's private code repository and is never published.
  • Analytics results are kept in the operator's private storage. They are not sold, shared, or transferred to any third party, and are not used for advertising.
  • No human other than the operator reads this data.

Compliance

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services and is subject to the Google Privacy Policy.

Revoking access and deletion

The operator can revoke the app's access at any time at myaccount.google.com/permissions. Once access is revoked, the app can no longer read or upload anything, and the stored credential and analytics data can be deleted on request.

Changes and contact

If this policy changes, the date above will be updated. Questions can be raised by opening an issue in this site's GitHub repository.
